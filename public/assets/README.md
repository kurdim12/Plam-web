placeholders (and the logo falls back to a "PalmGuard" wordmark), so the build
never breaks.

| `logo.png`         | Navbar    | Transparent background. Also the favicon.     |
| `logo-cream.png`   | Footer    | Cream/light version for the dark footer.      |

| `render-dark.jpg`  | Solution  | Device on a black background.                  |
